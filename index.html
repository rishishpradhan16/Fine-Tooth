Frequently asked

What is manual QA versus automation?

Manual QA involves human testers exploring workflows, evaluating user experience, checking visual layouts, and discovering unexpected edge cases that automated scripts often miss. Test automation uses scripted code to run repetitive, predictable checks (such as regression suites or critical path smoke tests) quickly and reliably within development pipelines. Both approaches complement each other.

Which frameworks do you support?

We work with industry-standard web automation frameworks including Selenium, Playwright, and Cypress. We select or adapt to the framework that best aligns with your codebase, technical requirements, and internal development workflow.

What does the $149 trial include?

The $149 Trial QA plan is a one-time assessment covering one project and one core flow or feature. It provides an initial manual assessment, structured findings, and reproducible bug reports with steps and screenshots. It does not include regression retesting, ongoing support, or automated testing.

Which project limits apply to each plan?

The Trial QA ($149 one-time), Basic ($299 or $449/mo), Pro ($699 or $899/mo), and Growth Manual ($1,299/mo) plans each cover exactly one project. The Growth with Automation plan ($1,699/mo) covers up to three projects. Additional projects require a separate plan or a customized quote.

How are monthly hours divided across projects?

Monthly hour allocations represent total testing hours per month for the selected plan, not hours per project. On the Growth plan with automation (which covers up to three projects), the 60 total monthly testing hours are shared across the included projects, not allocated as 60 hours per project. Cross-project priorities and hour allocations are agreed upon at project kickoff and tracked in weekly progress reports.

Are retesting and weekly reports included?

Yes, for all monthly plans (Basic, Pro, and Growth). Monthly plans include weekly progress reports and retesting of reported defects after fixes are deployed, subject to the plan's remaining hours. The one-time $149 Trial QA plan does not include regression retesting.

What happens when the monthly hours are exhausted?

Once your purchased monthly hours are reached, further testing pauses until the next billing cycle begins unless you request additional scoped hours under a separate quote. Unused hours do not roll over from one month to the next.

Do you test websites, APIs, mobile apps, and games?

Yes. We provide testing services across responsive web applications, REST APIs and integration points, mobile applications (iOS and Android viewports), and 2D/3D indie and mobile games including gameplay mechanics and progression validation.

How is custom automation code delivered and owned?

Automation code is developed according to the agreed engagement scope. Code ownership, repository delivery, and handover details follow the specific engagement terms agreed upon prior to project kickoff.
